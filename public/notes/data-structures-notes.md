## Overview

Free data structures and algorithms notes for BTECH — arrays, linked lists, stacks, queues,

and lab programs in C.

## Topics covered

| Unit | Topics |
|---|---|

| Stacks and queues | Stack operations, infix to postfix, expression evaluation, circular queue, priority queue, deque |

## Time complexity quick reference

| Algorithm | Best | Average | Worst |
|---|---|---|---|
| Bubble sort | O(n) | O(n²) | O(n²) |
| Insertion sort | O(n) | O(n²) | O(n²) |
| Merge sort | O(n log n) | O(n log n) | O(n log n) |
| Quick sort | O(n log n) | O(n log n) | O(n²) |
| Heap sort | O(n log n) | O(n log n) | O(n log n) |
| Binary search | O(1) | O(log n) | O(log n) |
